InvestTrack

An offline-first Flutter application for managing businesses, investments, and financial portfolios.

Features

• Portfolio Dashboard
• Business Management
• Transaction Ledger
• Analytics
• Financial Reports
• Notification & Reminder System
• Offline Storage using Isar
• Riverpod State Management
• Material 3 UI
• Responsive Design

Tech Stack

Flutter
Dart
Riverpod
Isar Database
Go Router
Material Design 3
